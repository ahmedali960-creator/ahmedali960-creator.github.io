## Deploy to GitHub Pages
1. Sign in at github.com as `ahmedali960-creator` and create a **public** repository named **`ahmedali960-creator.github.io`**.
2. Upload the *contents* of this folder (so `index.html` is at the repository root): Add file > Upload files, then Commit.
3. Open Settings > Pages. Under Build and deployment choose Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**, then Save.
4. Wait 1 to 3 minutes. The site will be at **https://ahmedali960-creator.github.io/**
